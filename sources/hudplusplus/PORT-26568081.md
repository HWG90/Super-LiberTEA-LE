# HudPlusPlus on game build 26568081

Helldivers 2 moved from Steam build 26251122 to 26568081 on 2026-11-11. This branch remaps the native
values to the new build. No runtime code changed: the Lua modules, settings, resources, patterns and call
descriptors are the 26251122 ones.

## What changed here

| File | Change |
| --- | --- |
| `src/data/numbers.lua` | 202 of 1,253 values, all addresses: 158 in code (two of them jump tables) and 44 in data. No struct offset, count, id or constant changed |
| `src/data/pin.lua` | SHA-256 of the 26568081 `bin/helldivers2.exe` and `data/game/game.dll` |
| `src/game/data.lua` | The digest of the numbers (the settings-cache key) |
| `migrations/26251122-to-26568081.json` | Old and new value of each of the above; `tests/test_bundle.lua` accepts exactly these differences from the v1.0.3 baseline |
| `tools/check.py`, `tests/test_bundle.lua` | Read `migrations/` |
| `tools/package.py` | `--guid`, `--line-map`, `--note` for a package that sits beside the old build's |

`src/data/patterns.lua` and the call heads in `src/data/calls.lua` are unchanged. On the pinned build
HudPlusPlus uses the baked numbers and never scans; on any other build it refuses.

## How the values were found

The work is in the Linux HD2 workspace, `builds/26568081/maps/hudplusplus/` (`port.py`, `hand_sites.py`,
`map-26568081.json`, `ADDRESSES.tsv`). Each value's 26251122 code site (HUD+'s own pattern hit, or the
instruction the 26251122 port recorded for a hand-found value) is located in the 26568081 memory capture
with RIP displacements and call targets wildcarded and every other byte exact, and the value is read again
there. Function entries are also compared body for body, globals by the instructions that reference them.

| State | Values | Meaning |
| --- | ---: | --- |
| verified | 1,215 | Read from the 26568081 image at a site proven to be the same code |
| inferred | 35 | Struct offsets whose code page is not in the 26568081 capture; kept at their 26251122 value |
| carried | 3 | `quiet_mark_kind` and `world_ui_slot` (constants HUD+ ships) and `stratagem_record_name` (no captured site on either build) |

Every address and every call target is verified. HUD+'s own resolver, run over the 26568081 image, agrees
on all 1,093 values it can find except the 15 whose patterns were already wrong or ambiguous on 26251122
(each proven by hand, as before).

## Needs a live read

The 35 inferred offsets sit on nine `game.dll` pages the capture never saw. A page decrypts when the game
first runs its code. The first two triggers were seen on 26251122; the others are guesses from the value
names.

| Page (26568081) | Values | Runs when |
| --- | --- | --- |
| 0x16b1000 | `component_card_ready`, `component_card_size`, `dead_label`, `hud_squad_death`, `squad_slot_base`, `squad_slot_stride`, `stratagem_row_mission` | A mission with other players (squad and stratagem-card HUD) |
| 0x818000 | `arc_weapon_interval`, `arc_weapon_map`, `arc_weapon_rows_at`, `arc_weapon_rows_stride`, `arc_weapon_wait` | Firing an arc weapon |
| 0x749000 | `charge_floor_at`, `charge_type_full_at`, `charge_type_low_at`, `charge_type_over_at` | Probably charging a charge weapon |
| 0x746000 | `deposit_instance_feeds_resource`, `weapon_assisted_reload_assist_need` | Probably an assisted reload |
| 0x85e000 | `area_drift`, `guide_centered`, `guide_heading`, `guide_salvo_interval`, `guide_shot_interval` | Probably an orbital barrage |
| 0x99d000 | seven `minigame_*` offsets | Probably a terminal mini-game with a countdown |
| 0x6ca000 | `targeting_map`, `targeting_row_stride`, `targeting_rows` | Probably a lock-on weapon |
| 0xf4e000 | `ability_owner_entity` | Probably a reinforcement call |
| 0x598000 | `static_position_stride` | Not known |

`live/hudplusplus_26568081_readonly.lua` in the workspace's `builds/26568081/mods/hudplusplus/` reads each of
these sites through LLtM and reports `WAIT` until its page has run. In game, check first: the Options page,
the weapon row and 3D weapon HUD, the backpack gauge with an arc weapon, squad status with other players,
and the eagle and orbital attack previews.

## Rebuild

```sh
python3 tools/build.py --check
python3 tools/check.py
python3 tools/package.py --assets-from /path/to/HudPlusPlus-LuaJIT-26251122 \
  --bundle lua/56e46a6dc1df0a13.lua --line-map lua/56e46a6dc1df0a13.map.json \
  --guid 2100b4f4-9d02-5ed7-86a7-7450c344f661 --out /path/to/HudPlusPlus-LuaJIT-26568081
```

For the next game build: capture it, run the workspace's `port.py` against the new images, then its
asserted rewrite script, which writes the next file in `migrations/`.
